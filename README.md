## Лабораторна робота 3: Базові типи домену (Склад)

Програма реалізує надійний імпорт даних предметної області «Склад» у вигляді незмінних `record`-типів із підтримкою різних форматів, розбором різнорідних рядків та збором статистики помилок.

### Формат вхідних даних (CSV)
* **Кодування:** UTF-8[cite: 1].
* **Роздільник:** крапка з комою (`;`)[cite: 1].
* **Наявність заголовка:** Так (рядки із заголовками та коментарями ігноруються)[cite: 1].
* **Структура рядків:** Дані розпізнаються за префіксом типу (Додаткове завдання 2)[cite: 1]:
  * **Товари:** `P;Id;Sku;Назва;Одиниця виміру;Кількість` (приклад: `P;P-001;SKU-001;Цемент;шт;120`)[cite: 1].
  * **Склади:** `W;Id;Назва;Розташування` (приклад: `W;W-001;Головний склад;Львів`)[cite: 1].

###  Виконані додаткові завдання
У цій роботі реалізовано всі три додаткові опційні завдання підвищеної складності[cite: 1]:
1. **Мультиформатний імпорт (JSON/CSV):** Залежно від розширення файлу (`.json` або `.csv`), програма через `switch expression` автоматично обирає потрібний імпортер (`ProductCsvImporter` або `ProductJsonImporter`)[cite: 1].
2. **Розпізнавання різнорідних рядків:** CSV-імпортер вміє читати з одного файлу різні сутності (`ProductDto` та `WarehouseDto`), використовуючи один `switch` і патерни списків для перевірки префіксів `P;` та `W;`[cite: 1].
3. **Статистика імпорту:** Перед основним виводом програма виводить одним рядком загальну статистику: усього оброблено, прийнято, пропущено та загальний відсоток помилок[cite: 1].
