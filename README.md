# Лабораторна робота 7: Звіти через LINQ

Аналітичне опрацювання колекції товарів складського обліку засобами LINQ to Objects. Уся логіка запитів інкапсульована в `ReportService`, результати повертаються у вигляді DTO (`StockLine`, `GroupSummary`), а запуск здійснюється через підкоманди CLI.

## Основні команди

* `dotnet run --project src/Cli -- report-top` — показує топ-5 товарів із найбільшим залишком на складі (детерміноване сортування за кількістю та SKU).
* `dotnet run --project src/Cli -- report-low` — виводить список товарів, залишок яких менший за 10 одиниць (стан дефіциту).
* `dotnet run --project src/Cli -- report-groups` — групує номенклатуру за одиницями виміру, підраховує кількість позицій і загальний залишок для кожної групи.
* `dotnet run --project src/Cli -- report-sum` — обчислює підсумкові агрегати каталогу: кількість позицій, загальну суму, середній залишок та максимальне значення.
* `dotnet run --project src/Cli -- demo-deferred` — демонструє різницю між відкладеним запитом і матеріалізованим знімком даних під час мутації списку.

## Додаткові команди

* `dotnet run --project src/Cli -- extra-join` — об'єднує дві різні колекції (товари та журнал рухів) за зовнішнім ключем у єдиний зведений DTO.
* `dotnet run --project src/Cli -- extra-top-ext` — демонструє роботу власного узагальненого методу-розширення `TopBy`.
* `dotnet run --project src/Cli -- extra-query-syntax` — формує звіт за групами через декларативний синтаксис запитів (`from ... group ... into`).
* `dotnet run --project src/Cli -- extra-benchmark` — вимірює таймером `Stopwatch` швидкість виконання ланцюжка на 100 000 записах із проміжним `ToList()` та без нього.

## Відкладене виконання (Deferred Execution)

Оператори `Where`, `Select`, `OrderBy` не обробляють джерело в момент оголошення, а лише описують конвеєр. Обчислення запускається тільки під час виклику термінальних методів (`Count()`, `ToList()`). У команді `demo-deferred` повторний виклик `query.Count()` бачить доданий товар, тоді як збережений через `ToList()` об'єкт `snapshot` залишається незмінним навіть після очищення вхідного списку.
